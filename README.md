# Ritme

Persoonlijke sport-PWA: 3× sport, 3× core en 3× mobility/posture per week.

- **Vandaag**: weekstand, dagritueel (de app kiest wat achterloopt), Beter dan niets, weekredder, zondagritueel om je week te plannen. Peilmetingen log je zelf, wanneer je wilt (Voortgang › Peil).
- **Trainen**: 36 workouts (AMRAP, For Time, Interval, Kracht), 9 routines (5/10/15 min) + combi, 5 gezinsworkouts, peilsessies, oefeningenbibliotheek met geanimeerde figuren.
- **Voortgang**: doelen per week, heatmap, minuten per sport, PR's met spookrace-historie, peiltrends en houdingsfoto's.

Alles draait in de browser, data blijft lokaal (IndexedDB). Geen build-stap: statische bestanden, te hosten op GitHub Pages.

Lokaal draaien: `python3 -m http.server` en open http://localhost:8000.
